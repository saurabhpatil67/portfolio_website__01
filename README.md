# 🚀 Animated React Portfolio

A modern, fully responsive, and highly interactive personal portfolio website built using **React**, **Framer Motion**, and **SCSS**. This project showcases my skills, projects, and experience through smooth animations, engaging user interactions, and a clean user interface.

## ✨ Features

### 🎯 Interactive User Experience

* Smooth page transitions and animations
* Hover and tap interaction effects
* Staggered text and component animations

### 🌄 Parallax Scrolling Effects

* Dynamic scrolling backgrounds
* Multiple layers moving at different speeds
* Immersive visual experience

### 🧭 Animated Sidebar Navigation

* Modern hamburger menu animation
* Expanding circular navigation effect
* Smooth open and close transitions

### 📊 Scroll Progress Indicator

* Sticky progress bar
* Real-time scroll tracking
* Animated scaling effect

### 🎨 SVG Animations

* Animated SVG path drawing
* Custom icon animations
* Morphing menu icon effects

### 📧 Contact Form Integration

* EmailJS integration
* Direct email sending without backend
* User-friendly contact section

### 🖱️ Custom Cursor

* Interactive custom mouse tracker
* Enhanced user engagement
* Smooth cursor movement effects

### ⚡ Performance Optimized

* Fast loading with Vite
* Optimized React components
* Smooth animation performance
